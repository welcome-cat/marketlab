# 농지 생산량 한도 제거 검증

현재 설정: 첫 노동자 생산성 65, 농지 생산량 한도 없음, 농지 이용료 기본 4,000원.
기계가 한 대 늘 때 농지 이용료는 기본액의 20%씩 증가한다. 비용 계산은 종전과 동일하다.
쌀에만 적용하던 기계당 기본 생산성 12% 추가 보너스를 0으로 조정했다.
기계의 노동 혼잡 완화와 고급 설비 업그레이드 효과는 유지한다.

12라운드 누적이윤 비교:

| 조건 | 이윤 |
|---|---:|
| 카페 | 2,045,405원 |
| 운동화 | 2,152,900원 |
| 쌀: 기존 600kg 한도, 추가 보너스 12% | 2,153,874원 |
| 쌀: 한도만 제거 | 5,237,228원 |
| 쌀: 한도 제거, 추가 보너스 제거 | 2,128,652원 |

초기 현금 30만원, 비교우위 업종, 매 라운드 이윤을 기준으로 고용 1~60명과 기계 구입 0~2대를 탐색한다.
기계는 2라운드부터 구입한다. 실제 앱의 생산비·한계생산·시장 거래 함수를 사용한다.
퀴즈·대출·업그레이드 구입·재해·다수 기업 경쟁은 제외하므로 최적 장기 전략이나 실제 수업 결과를 보장하지 않는다.
가격 ±20% 및 기계 구입 없는 조건도 실행한다.

`npm run simulate:balance -- --details`로 라운드별 고용·생산·판매·현금을 확인할 수 있다.
검증에는 600kg 초과 생산, 매 라운드 판매, 비음수 현금, 구버전 룸 한도 해제와 생산성 환산의 멱등성이 포함된다.
기존 docs/rice-balance.md는 농지 한도 제거 이전 실험 기록이다.
