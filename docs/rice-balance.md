# 쌀 매 라운드 판매 — 12라운드 검증

쌀 생산 주기 1라운드, 첫 노동자 생산성 90→65, 농지 한도 700→600kg.
기존 수요·공급 사건에 의한 생산성 배율은 유지하며 새 기준으로 한 번만 환산한다.
기존 재고는 추가 생성하지 않는다. 다음 생산·판매 결정에서 그대로 판매할 수 있다.
이미 확정된 과거 계획과 정산 내역은 다시 계산하지 않는다.

## 실행 조건

Node 24: `npm run simulate:balance -- --details`
실제 calculateProductionQuote와 calculateMarketClearing를 사용한다. Firebase 연결은 차단한다.
초기 현금 30만원, 비교우위 업종, 12라운드, 최대 고용 탐색 60명, 2라운드부터 기계 최대 2대 구입.
각 라운드 현재 생산분의 예상 이윤을 최대화하는 선택이며 장기 최적 전략은 아니다.
퀴즈·대출·업그레이드·재해·다수 기업 경쟁은 제외한다. 가격 ±20%와 기계 투자 유무는 별도 비교한다.
3라운드 판매 비교는 동일한 단기 선택 규칙이라 현금 부족에 취약하며, 기존 방식의 최적 수익이라는 뜻은 아니다.

## 결과

기본가격에서 카페 2,045,405원, 운동화 2,152,900원, 변경 전 수치로 매 라운드 판매하는 쌀 2,696,344원,
조정 후 쌀 2,153,874원. 쌀은 카페 대비 약 +5.3%, 운동화와 유사하다.
무투자 쌀 누적이윤 1,046,800원. 가격 하락 조건에서는 낮은 재료비로 방어력이 높고, 상승 조건에서는 운동화 수익성이 더 커진다.
실제 수업에서의 추가 밸런스 관찰이 필요하다.
